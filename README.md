# 元认知 · 退一步，看着自己思考

问题引导型的元认知互动页：5 节基础内容（基础认识 / 决定因素 / 影响机制 / 产生后果 / 应用方法）+ 三模式互动（浏览 / 引导 / 测一测）+ **AI 认知解答**。

AI 认知解答用「高级元认知」思考框架（澄清本质 → 觉察认知 → 挑战假设 → 生成方案 → 信心校准 → 语境重构）帮你把「不知道怎么办」的事想清楚，看到自己没看见的那一层。

内容源自 198 篇元认知研究文献（心理科学进展 / 心理学报 / 教育类核心期刊）；思考框架融合 E-P-I-C 生成式认知逻辑与批判性思维 14 类推理结构。
